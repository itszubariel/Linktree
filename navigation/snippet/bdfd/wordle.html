Wordle Game.

A fully functional Wordle game for Discord bots with visual feedback using colored buttons. Uses $awaitFunc for real-time gameplay and $httpGet to fetch random words and validate guesses.

// how to use

Add the !wordle trigger command and the $awaitedCommand[wordle;] handler. Create two user variables: wordle (empty) and active (set to "no").

// features

5-letter word guessing with color-coded feedback (🟩 correct position, 🟦 wrong position, ⬛ not in word), 5 attempts to guess, real-time word validation via API, and automatic game state management.
